开箱指南 ​

欢迎使用 CardputerZero！本指南帮助你快速上手。

包装内容 ​

  • CardputerZero 设备
  • USB-C 充电线
  • MicroSD 卡（完整版：32GB 预装系统）
  • 快速入门卡

首次启动 ​

  1. 插入 MicroSD 卡（如果未预装）
  2. 按下侧面电源键
  3. 等待约 30 秒系统启动
  4. APPLauncher 主界面出现

连接 WiFi ​

  1. 在主界面向右滑动到 Settings
  2. 选择 WiFi → Scan
  3. 从列表中选择你的网络
  4. 用键盘输入密码
  5. 完成！

基本操作 ​

按键功能
← →主界面切换应用
OK / Enter启动选中的应用
ESC返回 / 回到主界面
Fn + 按键功能快捷键
Ctrl+Alt+S截屏

你能做什么？ ​

  • 🎮 玩游戏 — 俄罗斯方块、乒乓、2048、小行星等
  • 💻 终端 — 完整 Bash、Python、SSH
  • 📡 网络工具 — WiFi 扫描、IP 面板、SSH 客户端
  • 🎵 音乐 — 播放音频文件
  • 📷 拍照 — 使用摄像头（完整版）
  • 🔧 硬件 — GPIO 控制、LoRa、Mesh 组网
  • 📦 安装应用 — 从 AppStore 浏览安装
