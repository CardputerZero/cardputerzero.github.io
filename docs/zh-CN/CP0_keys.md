# CardputerZero 按键规范

## 固定功能键

侧面 Boot 键：用于开机前触发 USB 启动。<br>
侧面 USB-SW 滑块：用于切换 USB 通路。<br>
右上角电源开关：向右拨动开机，向左拨动触发关机流程（不是直接断电）。<br>
左上角 ESC 键：短按 ESC，长按回到 HOME。<br>
右上角 TAB 键：短按等于标准 TAB 键，长按开始 AI 语音输入（该功能尚未完成）。<br>

## 修饰键

sym 键用于输入符号，对应键盘贴纸上的蓝色部分；<br>
shift 键用于输入大写字母；<br>
fn 键用于组合功能键，对应键盘贴纸上的橙色部分，具体见下文。<br>

**sym**、**shift**、**fn** 三个修饰键的触发逻辑：
- **短按一次修饰键**，对应的指示灯**慢闪**，按下任意一个数字字母按键将输出对应结果并退出修饰状态，或者再次短按修饰键退出修饰状态；
- **短按两次修饰键**，对应的指示灯**快闪**，可连续按下多个数字字母按键（用于连续输入多个符号、大写字母等），短按一次或两次修饰键退出修饰状态；
- **按住修饰键不放**，对应的指示灯**常亮**，可按下一个或多个数字字母按键，松开修饰键退出修饰状态。

**ctrl**、**alt** 键的使用方式与标准键盘一致。

## 组合功能键

fn + 数字 1~9 = F1~F9<br>
fn + 数字 0 = F10<br>
fn + 字母 O = F11<br>
fn + 字母 P = F12<br>
fn + 退格（向左删除）= DELETE（向右删除）<br>
fn + 字母 Q = 播放 / 暂停<br>
fn + 字母 W = 上一曲<br>
fn + 字母 E = 下一曲<br>
fn + 字母 U = 降低屏幕亮度<br>
fn + 字母 I = 提高屏幕亮度<br>
fn + 字母 A = 静音<br>
fn + 字母 S = 减小音量<br>
fn + 字母 D = 增大音量<br>
fn + 字母 F = 向上方向键<br>
fn + 字母 Z = 向左方向键<br>
fn + 字母 X = 向下方向键<br>
fn + 字母 C = 向右方向键<br>
fn + 字母 H = 显示 / 隐藏应用说明<br>
fn + 字母 J = 截屏（PrintScreen 键）<br>
fn + 字母 K = 标准 Home 键<br>
fn + 字母 L = 标准 PageUp 键<br>
fn + 字母 M = 标准 PageDown 键<br>
fn + 字母 B = 标准 Insert 键<br>
fn + 字母 N = 标准 End 键<br>

## 推荐按键设计

CardputerZero 的屏幕与其下方数字键 4~8 的位置对应，推荐利用这五个键执行常用操作。如下图所示，在屏幕底部用图标和 / 或文字说明各个按键的功能，下方用一条竖直短线指向按键。五个图标**中心**的横坐标分别为 `180, 236, 292, 348, 404`，纵坐标推荐 `153`，图标尺寸推荐 `22 * 22`。

除了数字键 4~8，也可以使用其他按键比如 OK（Enter）、空格、ESC、字母键等，此时推荐在屏幕底部说明可用按键及对应的功能，如下图所示。

**方向键特殊处理**：非字母输入状态下，推荐兼容直接使用 F、Z、X、C 字母键作为方向键，而不是必须处于 fn 修饰状态，这有利于用户体验。
