# CardputerZero キー仕様

![latest_key_sticker](assets/docs/latest_key_sticker.png){width=60%}

## 固定機能キー

側面の Boot キー：電源投入前に USB ブートモードを起動するために使用します。<br>
側面の USB-SW スライダー：USB 接続経路を切り替えるために使用します。<br>
右上の電源スイッチ：右にスライドすると電源が入ります。左にスライドするとシャットダウン処理を開始します（電源を即座に遮断するわけではありません）。<br>
左上の ESC キー：短押しで ESC を入力し、長押しで HOME に戻ります。<br>
右上の TAB キー：短押しで標準の TAB キーとして動作し、長押しで AI 音声入力を開始します（この機能はまだ実装されていません）。<br>

## 修飾キー

sym キーは記号入力に使用し、キーボードオーバーレイの青色の刻印に対応します。<br>
shift キーは大文字のアルファベットを入力するために使用します。<br>
fn キーはファンクションキーとの組み合わせに使用し、キーボードオーバーレイのオレンジ色の刻印に対応します。詳細は以下をご覧ください。<br>

**sym**、**shift**、**fn** 修飾キーの動作仕様：
- **修飾キーを 1 回短押し**すると、対応するインジケーターが**ゆっくり点滅**します。任意の英数字キーを押すと対応する文字が入力され、修飾モードを終了します。または、修飾キーをもう一度短押しすると修飾モードを終了します。
- **修飾キーを 2 回短押し**すると、対応するインジケーターが**速く点滅**します。複数の英数字キーを連続して入力できます（複数の記号や大文字を連続入力する場合など）。修飾キーを 1 回または 2 回短押しすると修飾モードを終了します。
- **修飾キーを押したまま保持**すると、対応するインジケーターが**点灯したまま**になります。1 つまたは複数の英数字キーを押すことができ、修飾キーを離すと修飾モードを終了します。

![double_click_shift](assets/docs/double_click_shift.png){width=40%} ![hold_shift](assets/docs/hold_shift.png){width=40%}

**ctrl** キーおよび **alt** キーの動作は、標準キーボードと同じです。

## ファンクションキーの組み合わせ

fn + 数字 1~9 = F1~F9<br>
fn + 数字 0 = F10<br>
fn + 英字 O = F11<br>
fn + 英字 P = F12<br>
fn + Backspace（左方向の削除）= DELETE（右方向の削除）<br>
fn + 英字 Q = 再生 / 一時停止<br>
fn + 英字 W = 前の曲<br>
fn + 英字 E = 次の曲<br>
fn + 英字 U = 画面の明るさを下げる<br>
fn + 英字 I = 画面の明るさを上げる<br>
fn + 英字 A = ミュート<br>
fn + 英字 S = 音量を下げる<br>
fn + 英字 D = 音量を上げる<br>
fn + 英字 F = ↑<br>
fn + 英字 Z = ←<br>
fn + 英字 X = ↓<br>
fn + 英字 C = →<br>
fn + 英字 H = アプリケーションのヘルプを表示 / 非表示<br>
fn + 英字 J = スクリーンショット（PrintScreen キー）<br>
fn + 英字 K = 標準の Home キー<br>
fn + 英字 L = 標準の PageUp キー<br>
fn + 英字 M = 標準の PageDown キー<br>
fn + 英字 B = 標準の Insert キー<br>
fn + 英字 N = 標準の End キー<br>

## 推奨キー設計

CardputerZero の画面は、その下にある数字キー 4~8 の位置に対応しています。そのため、この 5 つのキーを頻繁に使用する操作に割り当てることを推奨します。下図のように、画面下部に各キーの機能を示すアイコンおよび / またはテキストを表示し、その下に短い縦線で対応するキーを示してください。5 つのアイコンの**中心**座標は、それぞれ X 座標 `180, 236, 292, 348, 404`、Y 座標は `153` を推奨し、アイコンサイズは `22 * 22` を推奨します。

![screen_keys_1](assets/docs/screen_keys_1.png){width=60%}

数字キー 4~8 以外にも、OK（Enter）、Space、ESC、英字キーなどを使用できます。その場合は、下図のように画面下部に使用可能なキーとその機能を表示することを推奨します。

![screen_keys_2](assets/docs/screen_keys_2.png){width=60%}

**方向キーの特別な扱い:** テキスト入力モード以外では、fn 修飾キーを押さなくても、F、Z、X、C の各英字キーを方向キーとして直接使用できるようにすることを推奨します。これにより、より優れたユーザー体験を実現できます。
