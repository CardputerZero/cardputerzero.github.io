# CardputerZero アプリケーション開発ガイドライン

## メタデータ

- deb インストールパッケージファイル名：`packagename_version-revision_arm64.deb`

- アプリケーション名：できるだけ短くしてください。CardputerZero ランチャーおよびストアに表示されます。
- パッケージ名：すべて小文字で指定してください。スペースは使用できません。区切り文字としてハイフン（-）を使用できます。
- アイコン：PNG 形式、サイズ 256*256（各場所で必要なサイズに自動的に拡大・縮小されます）。アイコン自体に角丸や枠を付けることは推奨しません。
- バージョン
- スクリーンショット：サイズ 320*170（CardputerZero の画面サイズ）。複数枚のスクリーンショットを推奨します。
- 説明：デフォルトは英語です。日本語と中国語にも対応できます。
- カテゴリ：下記のカテゴリ一覧から 1〜2 個を必ず選択してください。
- 権限と実行要件：下記の各要件について、アプリケーションが必要とするかどうかを必ず宣言してください。
- 作者
- 作者メールアドレス
- オープンソース URL
- ライセンス
- ストア共有コード：4 桁の英数字。アプリケーションをすばやく検索するために使用します。

### 権限と実行要件

各アプリケーションは、以下の各要件が必要かどうかを必ず宣言してください：

- カメラへのアクセス
- マイクへのアクセス
- IMU の使用
- ネットワークの使用
- 外部ハードウェアが必要
- バックグラウンドで継続実行可能
- 外部ディスプレイをサポート

root 権限で実行されるアプリケーションの公開は禁止されています。

## フォント

システムには以下のフォントがインストールされています。優先して使用することを推奨します：

- 欧文（ラテン文字、ギリシャ文字、キリル文字など）用：DejaVu Sans / Serif
- ターミナル、コード用：JetBrains Mono
- CJK（中国語・日本語・韓国語）用：Noto CJK Sans / Serif（適切な地域・言語バリアントを選択してください）

表示品質を確保するため、ほとんどの画面では 12px 以上のフォントサイズと、Regular 以上の太さのフォントウェイトを使用することを推奨します。

## ファイル保存場所

設定ファイル：`$HOME/.config/YourApp/`
