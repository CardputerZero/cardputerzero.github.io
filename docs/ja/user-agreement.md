# CardputerZero Hub ユーザー・開発者規約

本規約は CardputerZero AppStore Hub のアプリ、メタデータ、スクリーンショット、バイナリ、コメント、リポジトリ活動の閲覧、ダウンロード、提出、保守、レビューに適用されます。

アプリを提出することは、本規約、開発者提出ポリシー、プライバシー要件、デバイス安全要件、メンテナーレビューに同意したことを意味します。

## 適用範囲

本規約は以下を対象にします。

- アプリ metadata。
- ソースコード。
- Debian パッケージとその他バイナリ。
- アイコンとスクリーンショット。
- README。
- Pull Request、Issue、Discussions、コメント。
- registry ファイルと生成された静的ページ。

Hub は公開ディレクトリと registry であり、全アプリの完全な安全監査を意味しません。ユーザーはインストール前に権限、プライバシー、ソース公開度、URL、checksum、リスク、審査状態を確認してください。

## 開発者の責任

開発者は次を守る必要があります。

- 追跡可能な GitHub ID で提出する。
- コード、素材、バイナリを配布する権利を持つ。
- 正確で完全な metadata を提供する。
- 権限、プライバシー、ネットワーク、デバイスアクセス、外部機器要件を宣言する。
- URL と checksum を最新に保つ。
- メンテナー審査に協力する。
- アプリ動作が変わったら metadata を更新する。

## Metadata の正確性

開発者は以下を隠したり誤解させたりしてはいけません。

- ネットワークアクセス。
- ファイルシステムアクセス。
- マイク、カメラ、センサー、GPS、キーボード利用。
- バックグラウンドサービス。
- 外部ハードウェア。
- HDMI 出力。
- アカウント、支払い、クラウドサービス依存。
- 商用利用制限と license 制限。
- 高 CPU、ストレージ、バッテリー、デバイスリスク。

## プライバシーとデータ

ユーザーデータへアクセス、保存、アップロード、処理する場合、以下を説明してください。

- どのデータにアクセスするか。
- なぜ必要か。
- データがデバイス外へ出るか。
- 誰が受け取るか。
- 保存期間。
- ユーザーが削除できるか。
- 第三者と共有するか。

アプリはデータ最小化を守るべきです。不必要な収集は拒否または掲載停止につながります。

## デバイス安全

アプリはデバイス、システムファイル、ユーザーデータ、外部ハードウェア、ネットワーク環境を意図的に損傷してはいけません。

ストレージ、システム設定、ネットワーク、GPIO、センサー、電源、音声、表示、外部モジュールに影響する場合は、リスクを明確に宣言してください。

未宣言の不安定化、データ破損、永続的な動作変更、過熱、または高リスク動作の隠蔽は拒否または掲載停止の対象です。

## ユーザー体験

アプリは基本的な利用品質を満たす必要があります。

- APPLaunch または実機 AppStore から起動できる。
- 認識できるアイコンがある。
- GUI は 320 x 170 に適合する。
- ユーザーをアプリ内に閉じ込めない。
- 通常起動で即時クラッシュしない。
- UI で意図的に欺かない。
- 実験的、未完成、特殊設定が必要な場合は明記する。

## 審査、掲載、掲載停止

CI 通過は自動掲載を意味しません。メンテナーは修正、追加説明、デモ、再現可能なビルド、テストログを要求できます。

状態は `pending`、`ci-passed`、`approved`、`needs-changes`、`rejected`、`deprecated`、`blocked` などになります。

ユーザー、デバイス、法律、プライバシー、コミュニティに明確なリスクがあるアプリは拒否、非表示、掲載停止、block されることがあります。

## 異議申し立て

開発者は Issue または Pull Request で拒否、掲載停止、blocked の判断に異議申し立てできます。アプリ UUID、タイトル、変更してほしい判断、修正説明、証拠を含めてください。
