Introduction ​

CardputerZero is a credit-card sized Linux computer built around the Raspberry Pi Compute Module Zero, designed for hackers, developers, and tinkerers.

What is CardputerZero? ​

A pocket-sized, all-in-one gadget featuring:

  • Quad-core ARM Cortex-A53 @ 1.0 GHz with 512MB RAM
  • 1.9" IPS LCD (320×170) with hardware PWM backlight
  • 46-key keyboard with function keys and modifiers
  • Full Linux (Raspberry Pi OS based)
  • Rich I/O: 2× USB-C, USB-A, RJ45 Ethernet, HDMI, Grove, GPIO header
  • Audio: I2S codec, 1W speaker, MEMS mic, 3.5mm jack
  • Wireless: WiFi 802.11bgn + Bluetooth 4.2 BLE
  • 1500mAh battery with BQ27220 fuel gauge

Who is this for? ​

  • Developers building LVGL/SDL2/Qt apps for embedded Linux
  • Hackers who want a portable Linux terminal with real keys
  • Makers connecting sensors, radios, cameras via GPIO/Grove/HAT
  • Students learning Linux, Python, C on real hardware
