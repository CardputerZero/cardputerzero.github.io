# Getting Started

Welcome to CardputerZero! This guide will help you set up your device and start using it.

## What's in the Box

- CardputerZero device
- USB-C charging cable
- MicroSD card (Full version: 32GB preloaded)
- Quick start card

## First Boot

1. **Insert MicroSD card** (if not pre-installed)
2. **Press the power button** on the side
3. Wait ~30 seconds for the system to boot
4. The **APPLauncher** home screen appears

## Connect to WiFi

1. Navigate to **Settings** (scroll right on home screen)
2. Select **WiFi** → **Scan**
3. Choose your network from the list
4. Enter password using the keyboard
5. Done! You're connected.

## Basic Navigation

| Key | Action |
|-----|--------|
| ← → | Scroll apps on home screen |
| OK / Enter | Launch selected app |
| ESC | Go back / Return to home |
| Fn + key | Function key shortcuts |
| Ctrl+Alt+S | Take screenshot |

## What Can You Do?

- 🎮 **Play games** — Tetris, Pong, 2048, Asteroids, and more
- 💻 **Terminal** — Full bash shell, Python, SSH
- 📡 **Network tools** — WiFi scanner, IP panel, SSH client
- 🎵 **Music** — Play audio files
- 📷 **Camera** — Take photos (Full version)
- 🔧 **Hack** — GPIO control, LoRa, Mesh networking
- 📦 **Install apps** — Browse and install from AppStore
