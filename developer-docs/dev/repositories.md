# Repositories

All CardputerZero source code lives in the [CardputerZero GitHub organization](https://github.com/CardputerZero).

## Core System

| Repository | Description |
|-----------|------------|
| [M5CardputerZero-Launcher](https://github.com/CardputerZero/M5CardputerZero-Launcher) | Home screen, Settings, APPLauncher (LVGL 9) |
| [cardputerzero-pigen](https://github.com/CardputerZero/cardputerzero-pigen) | OS image builder (pi-gen fork) |
| [M5CardputerZero-Driver-Overlays](https://github.com/CardputerZero/M5CardputerZero-Driver-Overlays) | Device tree overlays (LCD, keyboard, audio) |
